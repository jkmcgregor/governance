1. Separation of Duties (SoD) Violation Check

Identifies users holding toxic permission combinations (e.g., Software Engineering + Production Deployment rights).

SELECT 
    EmployeeID, 
    Name, 
    Department, 
    Roles
FROM 
    iam_user_access_logs
WHERE 
    Roles LIKE '%Developer%' 
    AND Roles LIKE '%Production Deployer%';

2. Stale / Inactive Accounts Audit (>90 Days)

Flags accounts violating identity lifecycle rules that have not authenticated within a 90-day window.

SELECT 
    EmployeeID, 
    Name, 
    Department, 
    LastLoginDate,
    CURRENT_DATE - LastLoginDate AS DaysInactive
FROM 
    iam_user_access_logs
WHERE 
    LastLoginDate < CURRENT_DATE - INTERVAL '90 days'
    AND AccountStatus = 'Active';

3. Excessive Privilege Escalation Check

Ensures administrative access is restricted exclusively to authorized technical and security personnel.

SELECT 
    EmployeeID, 
    Name, 
    Department, 
    IsAdmin
FROM 
    iam_user_access_logs
WHERE 
    IsAdmin = TRUE 
    AND Department NOT IN ('IT', 'Engineering', 'Security');
